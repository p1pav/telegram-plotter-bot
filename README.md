# Telegram Bot для приёма заявок на студенческие работы (Конспекты, рефераты, доклады)

Телеграм-бот на Python, который автоматизирует приём заявок на написание студенческих работ. Бот ведёт пользователя по пошаговому диалогу, собирает данные и отправляет их в закрытую группу модераторов, а также дублирует заявку в Google Sheets для удобного учёта. 
Бот разработан для работы с **текстовым плоттером** — устройством, которое автоматически пишет текст от руки. Именно поэтому на этапе заявки бот запрашивает **фотографию почерка** пользователя, чтобы плоттер мог воспроизвести нужный стиль письма.

## Функционал
*   **Пошаговый диалог (FSM) для сбора данных: тип работы, количество страниц, фото почерка, тема и текст.**
*   **Валидация ввода (бот просит число, если нужны страницы).**
*   **Отправка заявки в группу модераторов со всеми данными пользователя (ID, имя, юзернейм).**
*   **Двусторонняя связь: модератор делает реплай на сообщение бота в группе, и ответ отправляется пользователю в личные сообщения.**
*   **Автоматическая запись заявок в Google Sheets.**
*   **Консольное управление (команды `restart` и `stop`).**

## Стек технологий

*   **Python 3.11+**
*   **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API.
*   **gspread** — библиотека для работы с Google Sheets API.
*   **python-dotenv** — для загрузки переменных окружения из файла `.env`.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/p1pav/telegram-plotter-bot.git
cd telegram-plotter-bot
```

### 2. Создайте виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Создайте файл .env

В корне проекта создайте файл `.env` по примеру `.env.example` и заполните свои данные.

### 5. Настройте Google Sheets

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект.
3. Включите **Google Sheets API** и **Google Drive API**.
4. Создайте **Сервисный аккаунт** (Service Account).
5. Скачайте ключ в формате JSON, переименуйте в `credentials.json` и положите в корень проекта.
6. Откройте `credentials.json`, найдите `client_email` и дайте этой почте доступ **Редактора** к вашей Google Таблице.
7. В файле `.env` заполните переменную `SPREADSHEET_ID` (ID таблицы можно найти в её URL между /d/ и /edit).

Убедитесь, что вкладка (лист) в вашей Google Таблице называется так же, как в переменной SHEET_NAME (по умолчанию — Заявки). 

### 6. Запустите бота

```bash
python bot.py
```

## Важно

*   Бот должен быть **администратором** в группе модераторов, иначе он не увидит ответы.
*   Модератор должен отвечать пользователю через **реплай** на сообщение бота.
